# Accident case previews

These files are real surveillance previews published with the ACCIDENT benchmark. They are sample clips for the TraceLine demo. They are not a finding of fault.

Each clip is licensed [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).

Attribution: ACCIDENT benchmark, Lukas Picek, Michal Čermák, Marek Hanzl, and Vojtěch Čermák, CVPR Workshops 2026, https://accidentbench.github.io/.

Durations below are the container duration reported by `ffprobe`.
